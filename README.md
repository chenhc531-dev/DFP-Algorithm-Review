# DFP-Algorithm-Review
This repository contains the LaTeX source code for my homework, the paper [*Origin, Dilemma and Development of the DFP Algorithm*](Origin_Dilemma_and_Development_of_the_DFP_Algorithm.tex), along with the bibliography file [ref.bib](ref.bib) and GitHub Actions workflows for automatically compiling the PDF and checking spelling on each push.

The paper reviews the classic Davidon–Fletcher–Powell (DFP) quasi‑Newton method: its origin, theoretical convergence properties, the open problem of global convergence under inexact line searches, and recent improvements such as the Projection DFP algorithm.
